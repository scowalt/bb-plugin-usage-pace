# Usage Pace 0.5.2

Patch release that scopes autopilot to subscriptions available on the target host and computes effort pace per subscription.

## Changes

- **Host-scoped autopilot accounts.** Autopilot previously pooled every connected host's Claude accounts together regardless of which machine a thread runs on, and fell back to another machine's Antigravity reading when the target host had none. Both Claude and Antigravity standings now include only subscriptions available on the thread's host (host-local or `shared`-scoped).
- **Per-subscription overall effort pace.** Autopilot previously averaged Claude and Antigravity as two 50/50 provider buckets when picking an effort band. It now averages the individual weekly paces across all non-skipped subscriptions available on that host.

Minimum requirements are unchanged: **BB 0.48.1 / SDK 0.6.104**.
