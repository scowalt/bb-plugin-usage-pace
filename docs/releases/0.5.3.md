# Usage Pace 0.5.3

Patch release that lets autopilot recover quickly when a Gemini Neon check fails.

## Changes

- **Quick recheck after a failed check.** Autopilot kept a failed Gemini Neon check for five minutes. After a bb restart, the first check can land before the machine reconnects, so new threads went to Opus for five minutes even with `agy` working. A failure is now kept for 30 seconds, and the next thread after that waits up to 1.5 seconds for a fresh check. A good answer is still kept for five minutes.
- **Error detail in the reason.** The skip reason now includes bb's error detail, for example `Antigravity cannot start on this machine (failed: Host is not connected)`.

Minimum requirements are unchanged: **BB 0.48.1 / SDK 0.6.104**.

## Verification

- Added regression tests for the 30-second recheck and for the error detail in the reason; both fail on 0.5.2.
- Type checking, 604 Vitest tests, and the token-total tests pass.
- `dist/` is built with the installed bb, and `check:release` passes.
