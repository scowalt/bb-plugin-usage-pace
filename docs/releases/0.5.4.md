# Usage Pace 0.5.4

Patch release that flags an account that is signed out on one of your machines.

## Changes

- **Signed-out machines are flagged.** A usage source can report an account as signed out, or its login as expired, on one machine while the account works elsewhere. Usage Pace now shows an amber `signed out on <machine>` line on the account's strip row, a `Signed out on <machine>. Sign in there to use this account on that machine.` line on its dialog card, and the same line in `bb usage-pace`. `--json` lists the machines in each account's `signedOutHosts`. Before, nothing showed the gap; only the account's low pace hinted at it. A plugin reports these machines through `account-sign-ins.v1.listSignedOut`, which Claude Accounts 0.3.0 implements.
- **Autopilot skips the account on that machine.** Autopilot no longer counts an account as usable on a machine where it is signed out. On scott-beelink-ubuntu, with account B signed out there, autopilot had picked effort xhigh from B's 0.2× pace when the two usable accounts called for medium.
- **Server-only view keeps the account.** An account signed out on the server machine stays in the server-only view, so the flag shows.

Minimum requirements are unchanged: **BB 0.48.1 / SDK 0.6.104**.
