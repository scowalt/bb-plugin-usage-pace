# Usage Pace 0.4.8

Patch release that keeps an account's pool weight when a newer source reports its plan without a size.

## Changes

- **Plan size survives a merge.** An account read by several sources took its plan from the freshest reading. Usage Pace's own Claude Code source reads the plan from the local login, which can name a plan such as `ultra` with no `max_Nx` rate-limit tier. When that source answered last, the account's plan lost its multiplier, its pool weight became unknown, and the pool turned **partial**, so the weight depended on which source happened to answer last. Merged accounts now keep the freshest plan whose size is known, such as Claude Accounts' plan from Anthropic's profile, and fall back to the freshest plan only when no source knows the size. Usage windows, status, and other fields still come from the freshest healthy reading.

Minimum requirements are unchanged: **BB 0.48.1 / SDK 0.6.104**.

## Verification

- A new `mergeAccounts` test merges an unsized newest reading with two older sized readings in four row orders and expects the newest sized plan and weight 20; it fails on 0.4.7 and passes now. A second test keeps the freshest unsized plan when no source knows the size.
- Type checking, 448 Vitest tests, 3 token-total tests, and comment-policy checks pass.
- Built with BB 0.48.1. `check:release` passes, including the isolated production-only rebuild.

## Install or upgrade

For a new installation:

```sh
bb plugin install 'git:https://github.com/scowalt/bb-plugin-usage-pace.git@v0.4.8'
bb plugin config usage-pace set showStrip true
```

Reload the app UI to show the optional footer card. Use `@^0.4.8` instead of the exact tag to track compatible releases.

For an existing installation, inspect its source first:

```sh
bb plugin source usage-pace
```

Branch-tracking and compatible release-range installs can update while preserving settings:

```sh
bb plugin update usage-pace
```

Exact tags and commits remain pinned. Changing a pinned source may require removal and reinstall; **removal deletes settings, secrets, and schedules**, so record the configuration first. See [upgrade instructions](https://github.com/scowalt/bb-plugin-usage-pace/blob/v0.4.8/README.md#upgrades).

A **Pool weight overrides** entry added to work around this can be removed after upgrading.

Publishing this release does not install, update, reload, or reconfigure any live plugin.
