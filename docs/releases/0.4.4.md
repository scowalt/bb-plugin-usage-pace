# Usage Pace 0.4.4 — draft release notes

Patch release for the compact strip in bb 0.47's macOS desktop app.

## Fixes

- **The strip uses bb's supported sidebar footer API.** Its own footer icon opens a bordered, scrollable card above bb's footer buttons. The strip no longer inserts into bb's footer markup, where the desktop app's fixed 48px row hid account rows and pushed controls below the window.
- **Opens once, not after every refresh.** With `showStrip` enabled, the card opens at startup. bb allows one footer disclosure open at a time: opening Provider usage closes the strip; the Usage Pace icon brings it back. Background updates never take over the open card. bb does not remember the open disclosure across reloads.
- **Refresh and reset reads follow the right lifetimes.** Quota polling every five minutes while the page is visible, focus/visibility refreshes, and refresh after an exhausted account's reset passes continue with the strip closed. Saved-reset reads run only while the strip or details dialog is open, sharing the same inventory and badges.

`showStrip` remains off by default. Reload the app UI after changing it so bb can add or remove the registered footer item. The dialog, Provider usage pace ticks/per-tab errors/hidden providers, server-only filtering, CLI, and read-only reset behavior are unchanged. Release artifacts retain the **BB 0.44.0 / SDK 0.5.29** toolchain; minimum requirements and dependency pins are unchanged.

## New installations

After 0.4.4 is published:

```sh
bb plugin install 'git:https://github.com/scowalt/bb-plugin-usage-pace.git@v0.4.4'
bb plugin config usage-pace set showStrip true
```

Reload the app UI to show the optional card. Use `@^0.4.4` instead of the exact tag to track compatible releases.

## Upgrades

Inspect the installed source first:

```sh
bb plugin source usage-pace
```

For a branch-tracking install whose branch contains 0.4.4, or a release-range install admitting the published tag, update in place and preserve settings:

```sh
bb plugin update usage-pace
```

Exact tags and commits do not advance to a newer tag. Moving a pinned install, or changing an existing install to a tag or range, requires removal first. **Removal deletes settings, secrets, and schedules.** Record your configuration and restore it after reinstalling:

```sh
bb plugin config usage-pace
bb plugin remove usage-pace
bb plugin install 'git:https://github.com/scowalt/bb-plugin-usage-pace.git@v0.4.4'
```

Use `@^0.4.4` in the last command for compatible-release tracking. Do not install over an existing managed install. Reload the app UI after upgrading.
