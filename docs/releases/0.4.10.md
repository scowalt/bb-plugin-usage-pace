# Usage Pace 0.4.10

Patch release that shows Claude's new plan names and weighs Ultra by its weekly limit.

## Changes

- **New plan names.** On 2026-10-30 Anthropic renamed Max 5x to **Max** and Max 20x to **Ultra**. Claude accounts now show the new names. Sources that still report the old names, such as `Max 20x` or `Max (5x)`, are shown with the new ones. Claude's credentials still report Ultra as tier `default_claude_max_20x`, and the plugin maps that tier to Ultra.
- **Ultra weighs 10 in the pool.** Anthropic gives Ultra's weekly limit as 10× Pro. The 20 in the old name described the five-hour session only. Before, the pool gave a Max 20x account a weight of 20 and counted its weekly use twice as heavily as it should. Pool weights are now Pro 1, Max 5, and Ultra 10. **Pool weight overrides** still take precedence.
- The pool note and the **Pool weight overrides** description now give these weights.

bb's own Claude Code provider reports an Ultra account as `Max` with no size. When another source reads the same account, the pool uses that source's plan. When bb's provider is the only source, the account shows `Max` and the pool is marked partial, as before.

Minimum requirements are unchanged: **BB 0.48.1 / SDK 0.6.104**.

## Verification

- New tests cover the old-to-new mapping for `Max 20x`, `Max (5x)`, and an unsized `ultra` plan. They also check that an unsized `max` plan is left unchanged and that an Ultra account weighs 10. The tests for the reader and collector now expect `Ultra` and weight 10.
- Type checking, 453 Vitest tests, 3 token-total tests, and the comment-policy check pass.
- Built with BB 0.48.1. `check:release` passes, including the isolated production-only rebuild.

## Install or upgrade

For a new installation:

```sh
bb plugin install 'git:https://github.com/scowalt/bb-plugin-usage-pace.git@v0.4.10'
bb plugin config usage-pace set showStrip true
```

Reload the app UI to show the optional footer card. Use `@^0.4.10` instead of the exact tag to track compatible releases.

For an existing installation, inspect its source first:

```sh
bb plugin source usage-pace
```

Branch-tracking and compatible release-range installs can update while preserving settings:

```sh
bb plugin update usage-pace
```

Exact tags and commits remain pinned. Changing a pinned source may require removal and reinstall; **removal deletes settings, secrets, and schedules**, so record the configuration first. See [upgrade instructions](https://github.com/scowalt/bb-plugin-usage-pace/blob/v0.4.10/README.md#upgrades).

Publishing this release does not install, update, reload, or reconfigure any live plugin.
