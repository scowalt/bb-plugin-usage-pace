# Usage Pace 0.5.1

Patch release that lets model autopilot pick Gemini Neon without extra setup.

## Changes

- **Autopilot runs Gemini Neon on Usage Pace's own Antigravity provider.** Autopilot sent Gemini Neon threads to `acp-antigravity-acp`, which bb does not ship: its ACP registry lists Antigravity as a manual install. On a machine without a hand-added custom agent of exactly that id, autopilot skipped Gemini Neon with "Antigravity is not available on this machine" and always chose Opus. It now uses `usage-pace-antigravity`, the provider Usage Pace registers wherever `agy` is installed, which runs `agy acp` and lists `gemini-4-neon` with its effort levels. A custom Antigravity ACP agent is no longer needed. Turning off `antigravityUsage` removes that provider, so autopilot then skips Gemini Neon.

Minimum requirements are unchanged: **BB 0.48.1 / SDK 0.6.104**.

## Verification

- Autopilot tests now list a custom `acp-antigravity-acp` agent as available and the Usage Pace provider as unavailable, and check that autopilot follows the Usage Pace provider. With the old provider id restored, 4 autopilot tests fail.
- Type checking, 598 Vitest tests and 3 token-total tests pass.
- `dist/` is built with bb `0.50.2-fork.24`, and `check:release` and the comment-free source check pass.
