# Usage Pace 0.5.5

Patch release that weighs each subscription by its plan when autopilot sets effort.

## Changes

- **Effort weighs subscriptions by plan.** Autopilot set effort from a plain mean of every subscription's weekly pace, so one $20 Google plan counted as much as a $200 Claude Max 20x account. Early in Gemini's week its pace can read several times even: on Nov 23 Gemini at 6.91× pulled three Claude accounts at 0.98×, 1.25× and 0.28× up to 2.36×, and new Opus threads got effort low. Each pace is now weighted by its plan in units of a $20 monthly plan: Claude Max 20x 10, Max 5x 5, Pro 1, and the Google plan 1. The same reading now gives 1.04× and effort medium. Which model a thread gets is unchanged.

Minimum requirements are unchanged: **BB 0.48.1 / SDK 0.6.104**.

## Verification

- One new autopilot test, and four updated tests that assumed equal weights. All five fail on 0.5.4.
- Replaying the live Nov 23 usage snapshot gives `effort low at overall pace 2.36×` on 0.5.4 and `effort medium at overall pace 1.04×` on 0.5.5.
- Type checking, 632 Vitest tests, and the token-total tests pass.
- `dist/` is built with the installed bb, and `check:release` passes.
