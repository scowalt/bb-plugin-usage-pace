# Usage Pace 0.5.6

Patch release that keeps Google Antigravity usage visible when a quota group has not been used yet.

## Changes

- **Unused Antigravity windows no longer hide all usage.** `agy /usage` now reports a window nobody has used this period with `remaining_fraction` 1 and `reset_time` `1970-01-01T00:00:00Z`. Usage Pace read that as a reset that had already passed, marked the whole account stale, and showed "Usage unknown. Reset passed since last update." on every window, Gemini's included. A reset at or before the Unix epoch now means no reset is scheduled, so the window shows 0% used with no reset time.

Minimum requirements are unchanged: **BB 0.48.1 / SDK 0.6.104**.

## Verification

- Live `agy /usage` on beegent (Nov 26): Gemini Weekly 4.45% and 5h 17.81% keep their resets; Claude and GPT Weekly and 5h read 0% with no reset, and no window's reset has passed.
- Type checking, 633 Vitest tests, the token-total tests, and the comment policy pass.
- `dist/` is built with the installed bb, and `check:release` passes.
