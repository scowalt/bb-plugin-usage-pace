# Usage Pace 0.4.7

Patch release that restores the Claude Code and Codex logos for accounts read by Usage Pace's own source.

## Changes

- **Provider logos while disabled in bb.** Usage Pace takes each account's logo and tint from bb's provider list, and bb lists no metadata for a disabled provider. Accounts from the 0.4.6 Claude Code and Codex source therefore had no logo, and the strip and dialog showed the generic code mark. When bb lists no `claude-code` or `codex` provider, these accounts now use the logo bb still serves for it (`/api/v1/system/providers/<id>/logo`) and bb's tint: Claude orange `#D97757`, and the text colour for Codex. Accounts from an enabled bb provider keep bb's metadata unchanged.

Minimum requirements are unchanged: **BB 0.48.1 / SDK 0.6.104**.

## Verification

- The fallback-source `getUsage` test now asserts both logo URLs and tints; it fails on 0.4.6 and passes now.
- Type checking, 446 Vitest tests, 3 token-total tests, and comment-policy checks pass.
- Built with the installed BB 0.48.1. `check:release` passes with that bb's bundled npm, including the isolated production-only rebuild.
- On a live install with both bb providers disabled, `bb usage-pace --json` reports the logo URLs and tints, bb serves both logos (HTTP 200), and the sidebar strip shows the Claude and OpenAI marks.

## Install or upgrade

For a new installation:

```sh
bb plugin install 'git:https://github.com/scowalt/bb-plugin-usage-pace.git@v0.4.7'
bb plugin config usage-pace set showStrip true
```

Reload the app UI to show the optional footer card. Use `@^0.4.7` instead of the exact tag to track compatible releases.

For an existing installation, inspect its source first:

```sh
bb plugin source usage-pace
```

Branch-tracking and compatible release-range installs can update while preserving settings:

```sh
bb plugin update usage-pace
```

Exact tags and commits remain pinned. Changing a pinned source may require removal and reinstall; **removal deletes settings, secrets, and schedules**, so record the configuration first. See [upgrade instructions](https://github.com/scowalt/bb-plugin-usage-pace/blob/v0.4.7/README.md#upgrades).

Publishing this release does not install, update, reload, or reconfigure any live plugin.
